~/what-i-do

Cracked networks

The launcher-less side of Minecraft: online-mode=false, auth bridges, bot gates, ranks. Messier than it looks from the outside, and I like it that way.

Eaglercraft backends

My favourite thing to stand up — EaglerXServer behind Velocity, browser players in the same world as Java clients. Websockets, origins, skins, all of it.

Configuration work

Permissions, ranks, economies, menus, world rules, and every setting in between. I actually read the files people hand me, comments and all.

Performance & ops

Startup flags, chunk pre-gen, GC tuning, Spark reports, panel deploys, backups. I'd rather read a profile than argue about vibes.

~/portfolio — the dev behind the configs

I'm Grazer. I got into servers the usual way — joined one, thought "I could run that", and found out the hard way that it's 99% reading files. Turns out that's the part I love. Proxies and forwarding, permission trees and packet logs, and a terminal that hasn't been closed in weeks. I read documentation for fun and I keep notes on everything that breaks so it doesn't break twice. Not the loudest dev you'll meet — usually just the one with the docs open.
